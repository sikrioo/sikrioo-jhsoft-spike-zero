# 📄 우주 슈팅 PvP 아레나 모드 통합 기획서

**프로젝트:** Space Survival Shooter
**모드:** PvP Arena (1:1 / 2:2)
**목표:** 자원 쟁탈 기반 생존형 대전 모드 구현

---

# 1. 🎯 기획 의도

이 모드는 단순한 슈팅 PvP가 아니라

👉 **“자원을 확보하며 살아남는 경쟁 구조”**를 핵심으로 한다.

* 플레이어는 계속 움직여야 함
* 자원을 확보해야 생존 가능
* 교전은 자연스럽게 발생

---

# 2. 🎮 전체 게임 흐름 (중요)

```id="1q61ok"
메인 화면
 → 모드 선택 (1:1 / 2:2)
 → 대기룸 (매칭 & Bot 보정)
 → 게임 시작
 → 게임 플레이
 → 게임 종료
 → 결과 화면
 → 다음 게임 / 재시작
```

---

# 3. 🖥️ 메인 화면 설계

## 3.1 메인 메뉴

### 구성 요소

* [ ] 게임 시작 버튼
* [ ] 모드 선택 (1:1 / 2:2)
* [ ] (옵션) 튜토리얼 / 연습

---

### 동작

```txt
게임 시작 클릭 → 모드 선택 → 대기룸 진입
```

---

# 4. 👥 대기룸 (Lobby)

---

## 4.1 기본 구조

```js
lobby = {
  mode: "1v1" | "2v2",
  players: [],
  maxPlayers: 2 | 4,
  status: "waiting" | "ready"
}
```

---

## 4.2 플레이어 슬롯

| 상태    | 설명    |
| ----- | ----- |
| Human | 실제 유저 |
| Bot   | 자동 채움 |
| Empty | 대기    |

---

## 4.3 Bot 자동 보정 (핵심)

---

### ✔️ 1:1

```txt
1명 → Human vs Bot
2명 → Human vs Human
```

---

### ✔️ 2:2

```txt
1명 → H + B vs B + B
2명 → H + B vs H + B
3명 → H + H vs H + B
4명 → H + H vs H + H
```

---

## 4.4 시작 조건

* 최소 1명 (테스트 가능)
* 자동 Bot 채움 후 즉시 시작 가능

---

## 4.5 시작 버튼

```txt
조건 충족 시 → "게임 시작" 활성화
```

---

# 5. 🤖 Bot Player 시스템

---

## 5.1 정의

```js
player.type = "human" | "bot"
```

---

## 5.2 행동 방식 (간단 AI)

```js
botState = 
  "COLLECT_RESOURCE"
  "CHASE_ENEMY"
  "ATTACK"
  "RETREAT"
```

---

## 5.3 행동 규칙

| 조건    | 행동    |
| ----- | ----- |
| 산소 부족 | 산소 이동 |
| 탄약 부족 | 탄약 이동 |
| 체력 낮음 | 도망    |
| 적 가까움 | 공격    |
| 기본    | 자원 수집 |

---

## 5.4 목표

👉 테스트 + 게임 유지용
👉 고급 AI 필요 없음

---

# 6. 🎮 게임 시작 (Match Start)

---

## 6.1 초기화

* 플레이어 위치 랜덤 배치
* 자원 초기 생성
* 맵 랜덤 선택

---

## 6.2 시작 연출

```txt
3초 카운트다운 → 게임 시작
```

---

# 7. ⚔️ 게임 플레이 시스템

---

## 7.1 핵심 시스템

---

### 💎 자원 시스템

| 자원  | 효과            |
| --- | ------------- |
| 산소  | 지속 감소, 0 → 사망 |
| 에너지 | 스킬 사용         |
| 탄약  | 공격            |

---

### ⚡ 생존 압박

* 산소 지속 감소
* 위험 구역 생성

---

### 🔥 교전 유도

* 핫존 생성
* 고가치 자원 등장

---

## 7.2 승리 조건

```js
winCondition = "last_survivor"
```

* 마지막 생존 팀 승리

---

# 8. 🗺️ 맵 시스템

---

## 맵 종류

| 맵     | 특징         |
| ----- | ---------- |
| 성운    | 시야 제한 + 번개 |
| 소행성   | 장애물 회피     |
| 위성 잔해 | 고속 위험      |
| 냉기    | 차가운 연출     |

---
