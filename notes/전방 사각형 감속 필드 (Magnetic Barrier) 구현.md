# 🚀 [개발 의뢰서]

## 패시브 스킬: 전방 사각형 감속 필드 (Magnetic Barrier) 구현

---

## 1. 🎯 작업 목적

본 기능은 전투 시 **근접 압박 완화 및 공간 제어 능력**을 제공하기 위한 패시브 스킬 추가를 목적으로 한다.

* 플레이어가 능동적으로 위치를 잡도록 유도
* 전방 전투 라인 형성
* 기존 폭탄(원형) 시스템과 차별화된 전투 전략 제공

---

## 2. 🧠 기능 개요

> 플레이어 전방에 일정 주기로 **사각형 감속 필드**를 자동 생성하여
> 해당 영역에 진입한 적의 이동 속도를 감소시킨다.

---

## 3. ⚙️ 동작 방식

```txt
일정 시간 간격으로 자동 발동
↓
플레이어 진행 방향 전방에 사각형 필드 생성
↓
필드 유지 시간 동안 지속 적용
↓
필드 내부 적 이동 속도 감소
↓
지속 시간 종료 후 필드 제거
```

---

## 4. 📐 필드 생성 규칙

| 항목    | 값             |
| ----- | ------------- |
| 생성 위치 | 플레이어 전방       |
| 거리    | 약 100~140px   |
| 형태    | 사각형           |
| 방향    | 플레이어 진행 방향 기준 |
| 생성 방식 | 자동 (패시브)      |

---

## 5. 📊 기본 스펙

```js
slowField: {
  intervalMs: 3000,      // 생성 주기
  durationMs: 1800,      // 유지 시간
  width: 160,            // 가로
  height: 90,            // 세로
  spawnDistance: 120,    // 전방 생성 거리
  slowRate: 0.55         // 이동속도 55% 감소
}
```

---

## 6. 🧮 판정 로직

### 6.1 충돌 판정

* 사각형 범위 내 포함 여부 체크

```js
function isInsideRect(enemy, field) {
  return (
    enemy.x >= field.x &&
    enemy.x <= field.x + field.width &&
    enemy.y >= field.y &&
    enemy.y <= field.y + field.height
  );
}
```

---

### 6.2 효과 적용

```js
if (isInsideRect(enemy, field)) {
  enemy.speed *= slowRate;
}
```

※ 주의:

* 중복 적용 방지 필요
* 프레임마다 누적 감소되지 않도록 처리

---

## 7. 🎮 게임 플레이 효과

* 플레이어 전방 “안전 구역” 형성
* 적 접근 속도 지연 → 대응 시간 확보
* 포지셔닝 기반 플레이 강화

---

## 8. ⚡ 시각 효과 가이드

### 방향성

* “자기장 / 필드” 느낌
* 과도한 이펙트 금지 (웹 성능 고려)

### 구성 요소

* 얇은 사각형 테두리
* 내부 약한 색상 Fill (투명도 낮음)
* 미세한 펄스 애니메이션

### 색상

* 파란색 / 보라색 계열

---

## 9. 🚫 제한 사항

* 원형 폭탄 시스템과 중복 금지
* 복잡한 물리 효과 추가 금지
* 필드 개수 제한 필요 (최대 1~2개 권장)

---

## 10. 🧩 구현 고려 사항

* 필드 생성/삭제 타이밍 관리
* 플레이어 방향 기반 위치 계산
* 적 속도 원복 처리 필요
* 성능 저하 방지 (간단한 판정 유지)

---

## 11. 📌 기획 요약

> 전방에 자동 생성되는 사각형 감속 필드를 통해
> 플레이어가 전투 공간을 통제할 수 있도록 한다.

---

## 12. 🔥 기대 효과

* 단순하지만 체감 강한 패시브
* 기존 시스템과 충돌 없음
* 구현 난이도 대비 높은 효과
