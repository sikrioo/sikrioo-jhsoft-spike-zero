# 🚀 [개발 의뢰서]

## 웹 기반 우주 슈팅게임 UI/전투 요소 개선 및 행성 오브젝트 시스템 추가

---

## 1. 작업 목적

본 작업은 웹 기반 2D 슈팅게임의 **플레이 직관성, 전투 몰입감, 우주 환경 표현력**을 개선하기 위한 것이다.

주요 목표:

* 기체 선택 UX 개선
* HUD 단순화 및 가독성 향상
* 스킬(Afterburner) 상태의 직관적 표현
* 전투 지형 요소(행성) 추가
* 향후 확장 가능한 구조 설계
* **웹 환경에 적합한 렌더링 성능 유지 (중요)**

---

## 2. 핵심 요구사항 요약

```text
1. 인트로 → 기체 선택 → 게임 시작 흐름 추가
2. HUD를 최소 정보 중심으로 재구성
3. Afterburner 발동 시 시각적으로 즉시 인지 가능하게 개선
4. 충돌 가능한 행성 오브젝트 추가
5. 렌더링 성능 저하를 유발하는 방식은 지양
6. 확장 가능한 구조로 설계
```

## 3. 기능 상세 요구사항

---

## 3.1 인트로 → 기체 선택 흐름 추가

### 현재 문제

* 개발모드에서는 기체 선택 가능
* 일반 플레이에서는 선택 없이 바로 시작

---

### 변경 요구

```text
Intro Screen
 → Start Game
 → Ship Select Screen
 → Ship 선택
 → Game Start
```

---

### 구현 조건

* 기존 기체 선택 로직 재사용 가능 시 재사용
* 선택 결과는 GameState 또는 전역 상태에 저장
* 게임 진입 시 해당 기체로 초기화

---

## 3.2 HUD(UI) 정리

---

### 목표

* 전투 집중도를 높이기 위해 **필수 정보만 표시**

---

### 표시 대상

* HP
* MP
* XP
* 버프 상태
* 현재 주요 스킬 상태

---

### 배치

* 기본: **오른쪽 하단**
* 대안: 왼쪽 상단

---

### 디자인 가이드

* 단순한 바 형태 (Canvas 또는 DOM)
* 색상 구분:

```text
HP : Red
MP : Blue
XP : Yellow / Purple
```

---

### 추가 요구

* 디버그 정보 제거 또는 별도 토글로 이동
* 상세 정보는 메뉴/패널로 분리

---

## 3.3 Afterburner 시각화 개선 (중요)

---

### 목표

```text
사용 즉시 "강화 상태"를 직관적으로 인지
```

---

### 필수 구현 요소

#### 1) 기체 색상 변화 (필수)

* 엔진 / 날개 / 후방 일부 색상 변경
* 예:

  * 기본 → 중립 색
  * 활성 → 밝은 오렌지 / 네온 블루

---

#### 2) 엔진 이펙트 변화

* 분사 길이 증가
* 입자 수 증가
* 색상 변화

---

#### 3) 버프 HUD 표시

```text
[Afterburner ICON]  남은 시간 표시
```

---

### 선택 구현 요소 (성능 고려 후 적용)

* 잔상(Afterimage)
* 글로우
* 속도 라인

---

## 3.4 🪐 행성 오브젝트 시스템 추가

---

### 개념

* 단순 배경이 아닌 **충돌 가능한 맵 오브젝트**

---

### 기능 요구

* 총알 통과 ❌
* 기체 통과 ❌
* 충돌 시 데미지 없음

---

### 크기

```text
Small  : 기체 크기
Medium : 2배
Large  : 3배
```

---

### 역할

* 이동 차단
* 엄폐물
* 전투 구조 형성

---

### 충돌 처리

* 기체 → 이동 제한
* 총알 → 제거

---

## 3.5 행성 디자인 가이드 (경량화 필수)

---

### 요구 스타일

* 우주 행성 느낌
* 울퉁불퉁한 표면
* 크레이터/질감 표현
* 완전한 원형 금지 (약간 불규칙)

---

### ⚠️ 성능 제한 (중요)

웹 기반 환경이므로 다음을 반드시 준수:

#### 금지 / 지양

```text
- 고해상도 텍스처 (대용량 이미지)
- 실시간 쉐이더 연산
- 복잡한 노이즈 생성 (per-frame)
- 다중 레이어 블러/글로우 남용
```

---

#### 권장 방식

```text
- 저해상도 스프라이트 (texture atlas)
- 사전 생성된 이미지 사용
- 단순 원 + 노이즈 텍스처 조합
- Canvas draw 기반 경량 렌더링
```

---

#### 렌더링 전략

* 행성은 **정적 오브젝트로 처리**
* 매 프레임 계산 최소화
* 충돌 판정은 단순 원형 또는 근사 다각형 사용

---
