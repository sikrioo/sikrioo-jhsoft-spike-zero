# SPIKE-ZERO

<p align="center">
  <img src="./spike-zero-compact.png" alt="SPIKE-ZERO 메인 타이틀" width="720">
</p>

`SPIKE-ZERO`는 브라우저에서 실행되는 PixiJS 기반 탑다운 아케이드 슈팅 게임입니다.  
플레이어는 스테이지를 돌파하며 업그레이드를 선택하고, 웨이브와 보스전을 넘기며 생존해야 합니다.

## 게임 특징

- 프로덕션 인트로 이후 메인 타이틀에서 게임 시작
- WASD 이동, 마우스 조준, 클릭 사격 기반의 즉각적인 전투
- 뱀서라이크 방식의 레벨업 선택지 3종 제시
- 공격력, 방어력, 공격속도, HP, MP 등 주요 스탯 성장
- 패시브 스킬, 액티브 스킬, 무기 업그레이드 구성
- 머신건, 샷건, 레이저 3종 무기와 각기 다른 전투 감각
- Q/E/R 액티브 스킬 슬롯과 MP 시스템
- 관제사 브리핑, 보스 경고 연출, 스테이지 클리어 흐름
- 일반 플레이 모드와 보스/스테이지 테스트 모드

## 구현 현황

현재 스테이지 1~3까지 플레이 흐름이 구현되어 있습니다. 각 스테이지는 약 3분간 일반 적 웨이브를 버틴 뒤 WARNING 연출과 함께 보스전에 돌입하며, 보스전 전후로 짧은 관제사 브리핑 대사가 출력됩니다.

스킬은 약 20종이 준비되어 있고, 무기/패시브/액티브 선택지를 통해 매 플레이마다 다른 성장 방향을 만들 수 있습니다. 일반 적은 추적형, 미사일형, 측면 진입형, 포탑형, 돌격형, 자폭형 등 약 10종이 있으며, 보스는 3종과 각 보스별 2페이즈 패턴이 구현되어 있습니다.

스테이지별 일반 전투 음악, 보스전 음악, 2페이즈 전환 음악이 분리되어 있고, 미사일 폭발, 레벨업 등 주요 상황별 효과음도 들어가 있습니다. 아직 프로토타입 단계지만 핵심 플레이 루프는 어느 정도 완성된 상태이며, 현재는 테스트 모드로 밸런스를 조정하고 있습니다.

## 영감

개인적으로 좋아하는 `카우보이 비밥`의 분위기와 주인공 스파이크에 대한 애정이 게임 이름과 톤에 일부 반영되어 있습니다. 여성 관제사 캐릭터는 `레이`와 `마키마`처럼 차분하고 냉정한 인상을 좋아해서, 그런 이미지에서 가볍게 영향을 받았습니다.

## 향후 계획

- 최대 스테이지 8까지 확장
- 파일럿과 관제사 관계에 따른 엔딩 요소
- 대사와 브리핑을 활용한 간단한 시뮬레이션 요소
- 특정 시간 동안 생존하는 별도 모드
- 온라인 대전 모드
- 지속적인 밸런스, 연출, UI 업데이트

## 실행 방법

별도 빌드 과정 없이 정적 파일로 실행할 수 있습니다.

```text
index.html
```

브라우저에서 `index.html`을 열면 게임이 시작됩니다.  
PixiJS와 필터 라이브러리는 CDN을 사용하므로 인터넷 연결이 필요합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 | 사격 |
| Shift | 대시 |
| Q / E / R | 액티브 스킬 |
| 1 / 2 / 3 / 4 | 방향 슬라이드 |
| Esc / P | 일시정지 |

## 프로젝트 구조

```text
assets/                 음악, 효과음, 캐릭터 이미지
css/                    화면 스타일
js/core/                부트스트랩, 상태, 공통 유틸
js/data/                밸런스, 무기, 업그레이드, 대사, 리소스 매니페스트
js/entities/            플레이어 등 게임 오브젝트
js/render/              배경과 시각 효과
js/systems/             전투, 웨이브, UI, 스킬, 사운드, 보스 시스템
lab/                    실험용 프로토타입
index.html              메인 게임
intro.html              인트로 화면
```
